# Studio 03 — Creative Agency & Design Studio Template

A bold, modern, and production-grade multi-page website template designed for creative agencies, design studios, branding companies, architecture firms, and digital production teams.

## Highlights
- **Distinctive Visual Identity**: Oversized editorial typography, asymmetrical layouts, large visual exhibition spaces, and high-contrast styling.
- **Multi-Page Architecture**: Fully decoupled HTML pages for Home, Studio Overview (`overview.html`), Services & Capabilities (`features.html`), Portfolio Showcase (`showcase.html`), Studio Story (`about.html`), Reviews (`testimonials.html`), and Project Inquiries (`contact.html`).
- **Complete Theme System**: Full light, dark, and system-default themes with instant local storage persistence and zero flash of incorrect theme.
- **Interactive Components**: Client discovery form, portfolio filters, interactive modal previews, process timelines, and live studio clocks.
- **Zero-Bloat Performance**: Built on semantic HTML5, pure CSS variables, and lightweight modular JavaScript.
